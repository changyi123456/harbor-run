# 港灣疾走：製作規格

原創都市駕駛垂直切片，以港灣夜景、改裝跑車、霓虹商店、警方追逐為主題。畫面參考 `gameplay-concept.png`；採用 Blender 製作的風格化 PBR 3D 模型，保留概念的構圖與色彩，並非宣稱達到大型商業遊戲的寫實精度。

玩家駕車穿越 8 個檢查點、抵達港口；時間耗盡或車體毀損則任務失敗。可重新開始，最佳成績在本機保存。完整鍵盤與手機體感控制。主目標是桌面 WebGL2，手機遙控頁不啟動 3D 引擎。手機本機遊玩提供觸控備援。

## 美術與介面

全螢幕追車視角；銀色寬體雙門跑車、黑色車頂、紅色尾燈、黑色擴散器；藍紫暮色、暖色地平線、灰藍路面、青色導航與氮氣、桃紅招牌。建築使用倒角、窗框、底層商店、頂樓設施，街道有道路標線、棕櫚、路燈、車流、碼頭與貨櫃。模型以 GLB 匯出；來源保存在 art-source。

背景 #0b1019、表面 #121c2a、文字 #f1f5f5、次要文字 #a4b5c3、青色 #5ce8e1、珊瑚 #ff785d。標題採凝縮斜體大字，中文使用系統黑體。細邊框、少量半透明覆蓋層、開放式教學版面，不使用卡片堆疊。

可見文案：HARBOR RUN、港灣疾走、穿越檢查點，抵達港口、手機連線、暫停、WASD 駕駛 · Space 手煞車 · Shift 氮氣、km/h。任務時間、耐久、檢查點、連線狀態、畫質、教學與結算屬必要遊戲狀態延伸。

## 系統

Babylon.js 9.29 WebGL2，TypeScript + Vite。自訂固定 60Hz 的街機車輛模擬、建築碰撞、車流與追逐車。感測資料、輸入、模擬、渲染、HUD、網路各自有模組。

HTTPS GitHub Pages 只提供靜態頁面；PeerJS 公共服務負責 WebRTC 配對。體感資料透過 DataChannel，含房間隨機碼、序號、限流、校驗、斷線停止。公開信令服務是外部依賴；限制 NAT 的網路可能需要同一 Wi-Fi 或 TURN 服務。不能宣稱所有網路都保證連通。

手機校正採用重力在螢幕平面上的投影，減少橫拿／直拿軸混淆；以姿態事件作備援，無感測資料時提供觸控方向控制。開始按鈕直接要求感測器權限。校正、敏感度、斷線、重試、鎖屏／背景停止輸入均可见。

## 目標與驗證

首屏有實際 3D 場景和遊戲前操作指引。先驗證生產建置、模型驗證、桌面鍵盤、同瀏覽器不同頁面的 WebRTC 控制、手機尺寸、暫停／重置、儲存與 HTTPS 上線，再記錄無法實機驗證的項目。目標 60fps 桌面；省電畫質關閉重型反射與部分效果、限制像素比。初始模型 < 12MB。
