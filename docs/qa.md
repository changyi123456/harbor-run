# 驗證紀錄 · 2026-10-07

## 已完成

- Node.js 24 正式 TypeScript／Vite 建置通過；同一個 `dist` 使用 preview 進行瀏覽器驗證。
- 5 個領域測試通過：加速及轉向、碰撞解穿透及耐久、任務完成／重開／超時、網路輸入序號及非有限值拒絕、螢幕旋轉下的重力轉向。
- Khronos glTF Validator：城市、玩家跑車、追逐車、導航門均無 error 或 warning；導航門只有未使用 UV 的資訊提示。
- macOS Codex 內建瀏覽器：場景載入、鍵盤指引、W 加速、暫停、重開確認；Esc 暫停／繼續已實測修正；重開後恢復 (184,155)、速度 0、耐久 100。
- 遙控頁關閉後確認主遊戲進入暫停；補上以牆鐘時間執行的失聯監測，避免等候渲染迴圈才發現連線中斷。
- 兩個瀏覽器頁面用公共 PeerJS 信令完成 WebRTC 配對。遙控頁的油門按鈕確實改變主遊戲位置與速度；遙控開始會關閉配對及暫停視窗。
- 手機控制頁在 390×844 直向與 844×390 橫向檢查，主要踏板、方向備援、開始／暫停／校正都可操作。修正橫向高度不足後再次檢查。
- 配樂 AAC 解碼成功，長度約 50.6 秒、loop 設定開啟；開始後 currentTime 前進，音樂開關可暫停和恢復；音效有獨立開關。維持播放超過兩個循環後，currentTime 回到循環中的時間，沒有媒體錯誤。
- 1672×941 遊戲畫面抽樣約 120fps（這台電腦／此瀏覽器，並非所有裝置保證）。
- GitHub Actions 測試／建置／Pages 部署成功。公開 HTTPS 網址實測 GLB 載入、AAC 配樂解碼、WebRTC 配對及遙控油門，執行中沒有新的 console error／warning。

## 尚未實機驗證

- 沒有實體 iPhone／Android 在場，尚未驗證每種手機的動作權限、傾斜方向、實際延遲和握持手感；需由玩家用手機試玩。
- 沒有驗證所有 NAT／防火牆組合。公共信令和無專用 TURN 的連線可能在受限網路失敗。
- 沒有中低階手機長時間 GPU／電池／散熱測試；手機遙控頁不載入 3D 引擎。
- 關卡勝敗邏輯以領域測試驗證，尚未用人工駕駛完成全程通關。

視覺是都市駕駛垂直切片，並不等同 AAA 開放世界遊戲的製作規模。後續可增加道路表面紋理、近景細節、行人、更多任務和車輛。
